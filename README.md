# Distribuição de Quartos - Housekeeping

App para distribuir quartos de saída e serviço entre as housekeepers.

## Como usar online

1. Baixe o arquivo `distribuicao-housekeeping.html` (versão completa) da conversa com o Grok.
2. Neste repositório: **Add file → Upload files** → substitua o `index.html` pelo arquivo baixado.
3. Vá em **Settings → Pages** → Source: **Deploy from a branch** → **main** / **(root)** → Save.
4. Aguarde 1–2 minutos e abra:

**https://murilosc26.github.io/distribuicao-housekeeping/**

## Funcionalidades

- Colar lista de saídas e serviços
- Quartos familiares (contam como 2)
- Housekeepers com folga
- Distribuição automática (máx. 6 saídas)
- Edição manual do resultado
- Salva nomes e familiares no navegador (localStorage)
- Copiar / imprimir

## Arquivos

- `index.html` — a aplicação
- `.nojekyll` — para o GitHub Pages servir HTML puro
